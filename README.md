Esta introdução apresenta, de forma abrangente, o desenvolvimento de um sistema de gestão de aluguer de automóveis, elaborado como trabalho académico para a unidade curricular de Linguagens e Teoria da Computação, no âmbito do curso de Engenharia Informática da Escola Superior de Ciência e Tecnologia para o ano letivo 2024/2025.

O projeto tem por objetivo a criação de uma aplicação robusta e eficiente para gerir todas as operações relacionadas com o aluguer de automóveis na empresa fictícia “Rent Car Lda”. Inspirado numa proposta apresentada pelo professor José Arnaud, o sistema foi concebido utilizando a linguagem de programação Java, o que permitiu a aplicação de conceitos fundamentais da programação orientada a objetos (POO), como a modularidade, o encapsulamento e a reutilização de código, bem como a implementação de boas práticas de design de software.

A aplicação desenvolvida contempla diversas funcionalidades essenciais, entre as quais se destacam:
• Gestão de Automóveis: Registo, atualização, remoção e listagem de veículos, com validação para evitar duplicações e garantir a integridade dos dados.
• Gestão de Clientes: Administração dos dados dos clientes, assegurando que informações críticas, como número de Cartão de Cidadão e carta de condução, sejam únicas e validadas.
• Gestão de Alugueres: Criação e controlo dos alugueres, incluindo a validação das datas (garantindo que a data final não seja anterior à data inicial), verificação da disponibilidade do veículo e cálculo automático do valor total com base na duração do aluguer e no valor diário do automóvel.
• Geração de Relatórios e Listagens: Ferramentas que permitem ao utilizador consultar estatísticas e relatórios detalhados, como a relação de automóveis alugados versus disponíveis e a listagem de alugueres ordenados por data de entrega.

A interação com o sistema é realizada através de uma interface de linha de comando (CLI), construída para ser intuitiva e acessível, minimizando a necessidade de formação prévia por parte dos utilizadores. Adicionalmente, a utilização de uma classe de utilitários para a leitura e validação de entradas – o InputUtils – garante que os dados inseridos são consistentes, robustos e que os erros são tratados de forma clara e amigável.

Ao longo do desenvolvimento, foi dada especial importância ao planeamento e à estruturação do código, resultando numa arquitetura que segue o padrão MVC (Modelo-Visão-Controlador). Esta abordagem não só favorece a manutenção e a escalabilidade da aplicação, como também simplifica futuras expansões – como a integração com uma base de dados (SQL ou NoSQL) ou a evolução para uma interface gráfica utilizando JavaFX ou Swing –, tornando o sistema uma base sólida para soluções empresariais reais.

Em resumo, este projeto é a materialização de um esforço para integrar teoria e prática na área da computação, permitindo ao autor aplicar conhecimentos de estruturas de dados, algoritmos e boas práticas de engenharia de software num contexto que simula as exigências do mercado de aluguer de automóveis. Ao detalhar cada componente do sistema – desde o planeamento inicial e a implementação das funcionalidades principais até à análise dos algoritmos e fluxogramas – o trabalho evidencia não só o domínio técnico adquirido ao longo do curso, mas também a capacidade de desenvolver soluções de software que respondem a requisitos complexos e reais, contribuindo assim para a formação académica e para a futura inserção profissional na área da tecnologia.
